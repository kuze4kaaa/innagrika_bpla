# Назначение папки

Здесь сохранены старые разовые скрипты и снимки, использованные во время разработки интерфейса. Часть скриптов содержит пути для Windows и относится к более ранним именам переменных.

Эти файлы не входят в рабочую систему и не используются как доказательство прохождения испытаний. Актуальные автоматические проверки находятся в `../tests/`, а протокол сценариев С1-С8 - в `../docs/TEST_PROTOCOL.md`.
